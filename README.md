## 📌 About the Project

**GraphVista** is a Java-based Smart Route Planning System that demonstrates how graph algorithms can solve real-world route optimization problems.

It provides an interactive graphical interface where users can select source and destination locations, calculate optimal routes, compare different pathfinding algorithms, and manage road connections.

The project focuses on applying **Graph Theory, Dijkstra's Algorithm, and A* Search Algorithm** to make route planning more efficient and interactive.

## ✨ Key Features

* 🗺️ **Interactive Map Interface** – Select source and destination nodes directly from the map.
* 📍 **Smart Route Planning** – Find optimal routes between selected locations.
* ⚡ **Multiple Optimization Modes** – Choose between shortest distance and fastest travel time.
* 🔍 **Algorithm Comparison** – Compare Dijkstra's Algorithm and A* Search.
* 🚧 **Road Management** – Block or unblock road connections dynamically.
* 📊 **Performance Analysis** – View explored nodes and search execution time.
* 🧪 **Benchmark Testing** – Compare algorithm performance using generated grid-based test cases.
* 🔄 **Swap Locations** – Easily switch source and destination.

## 🧠 Algorithms Used

| Algorithm            | Purpose                                                      |
| -------------------- | ------------------------------------------------------------ |
| Dijkstra's Algorithm | Finds the shortest path based on the selected cost.          |
| A* Search Algorithm  | Uses a heuristic to guide the search toward the destination. |

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Anshika-Srivastava-28/GraphVista.git
```

### 2. Navigate to the Project Folder

```bash
cd GraphVista
```

### 3. Compile the Java Files

```bash
javac RoutePlanner.java RoutePlannerGUI.java
```

### 4. Run the Application

```bash
java RoutePlannerGUI
```

**Prerequisite:** Java Development Kit (JDK) installed on your system.
